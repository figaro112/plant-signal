## Ako pracovať (mini-návod)
1. Otvor príslušnú stránku vyššie a doplň obsah.
2. Pridaj odkazy na repozitár, video a demo (ak máš).
3. Ulož zmeny, commitni a pushni:
   ```bash
   git add .
   git commit -m "Update deliverables"
   git push
   ```
